┌───────────────────────────────────────────────────────────────┐
│                    🛒 PROCESS SALE (POS)                      │
└───────────────────────────────────────────────────────────────┘

1. Search Product:
   ▸ Type nama produk di search bar
   ▸ OR scan barcode
   ▸ Pilih dari list produk

2. Add to Cart:
   ▸ Click "Add to Cart"
   ▸ Produk masuk ke cart di kanan

3. Choose Price Type:
   ▸ Click "Eceran" untuk harga retail
   ▸ Click "Grosir" untuk harga wholesale
   ▸ Harga otomatis adjust

4. Enter Payment:
   ▸ Lihat Total di bottom
   ▸ Input jumlah pembayaran
   ▸ Kembalian auto-calculate

5. Process Payment:
   ▸ Click "Process Payment"
   ▸ Stok otomatis berkurang
   ▸ Transaksi tersimpan

6. Print Receipt:
   ▸ Receipt preview otomatis muncul
   ▸ Click "Print" / Ctrl+P
   ▸ Pilih printer thermal (80mm)
   ▸ Print receipt untuk customer


┌───────────────────────────────────────────────────────────────┐
│                  📦 ADD PRODUCT (Admin Only)                  │
└───────────────────────────────────────────────────────────────┘

Method 1 - Manual (1 produk):
  1. Click "Inventory" di sidebar
  2. Click "Tambah Produk"
  3. Fill form:
     ▸ Nama Produk
     ▸ Kategori (pilih atau buat baru)
     ▸ Harga Eceran (Retail)
     ▸ Harga Grosir (Wholesale)
     ▸ Harga Modal (optional)
     ▸ Stock (jumlah unit)
     ▸ Barcode (optional)
  4. Click "Add Product"
  5. ✅ Produk ditambahkan!

Method 2 - CSV Import (bulk):
  1. Click "Inventory" di sidebar
  2. Click "Import CSV"
  3. Select CSV file (format: products_template.csv)
  4. Click "Import"
  5. Wait for processing
  6. ✅ Check results (success/partial/failed)

┌───────────────────────────────────────────────────────────────┐
│                   🆘 TROUBLESHOOTING                          │
└───────────────────────────────────────────────────────────────┘

❌ Can't Login:
  → Check email/password correct
  → Check caps lock off
  → Try forgot password
  → Contact admin

❌ Product Not Found:
  → Check spelling
  → Use barcode scanner
  → Check product exists in inventory
  → Ask admin to add product

❌ Print Not Working:
  → Check printer ON
  → Check paper loaded
  → Check USB/Bluetooth connection
  → Try Print Preview first (Ctrl+P)
  → Check printer selected (80mm thermal)

❌ Stok Habis:
  → Cannot add to cart
  → Check inventory for stock level
  → Contact admin to restock
  → Use search to find alternative

❌ App Loading Slow:
  → Check internet connection
  → Clear browser cache
  → Reload page (F5)
  → Check other tabs closed

❌ Offline Mode Stuck:
  → Check internet connection
  → Click sync button manually
  → Wait for auto-sync (every 30s)
  → Reload page if needed
